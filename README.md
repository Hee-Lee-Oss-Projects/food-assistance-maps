**food-assistance-maps** is an open, **freshness-tracked directory dataset** of food banks, food pantries, community fridges, soup kitchens / hot-meal programs, school and summer meal sites, and related food-assistance services, organized by region and published as open data plus a thin, accessible directory/map view. The core deliverable is **data, not an app**: a clean, interoperable, provenance-rich dataset that anyone — 211 services, mutual-aid groups, civic apps, map makers — can reuse to help food-insecure people find a place to get food **today**.
